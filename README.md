## Overview

The IRC adapter reads and writes IRC messages in [csp](https://github.com/point72/csp) graphs. It wraps the IRC backend from [chatom](https://github.com/1kbgz/chatom), which uses Python's standard library, so it needs no extra SDK.

## Chat Framework

[`csp-bot`](https://github.com/Point72/csp-bot) is a framework for writing cross-platform, command oriented chat bots.

## Installation

Install with `pip`:

```bash
pip install csp csp-adapter-irc
```
